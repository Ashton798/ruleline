只用测试钱包和测试币。监听合约创建交易附带 0.1 lREACT；金库创建交易附带 0.01 Sepolia ETH；部署、绑定和转账各有额外 Gas。具体金额以 MetaMask 为准，预存并不保证后续费用充足。账户需有足够的测试币和要自转的 RCAMP；不要将私钥、助记词或 API Key 发给任何人。

## 用户亲自操作

1. 在项目目录运行 README 中的启动命令，打开 <http://127.0.0.1:4188/>，点击“连接钱包”，在 MetaMask 选择测试账户并授权连接。
2. 填写“当指定账户转账达到 10 RCAMP 时，暂停测试金库”，检查监控账户，点击“本地解析”。
3. 检查完整账户、代币、阈值、Sepolia 和 Lasna、金库部署计划以及测试网费用；理解一次触发后退订，再勾选确认。
4. 点击“部署监听合约”。若钱包要求切换 Lasna，请自行确认切换，然后再点击部署；在 MetaMask 核对 0.1 lREACT 和 Gas，自行确认。等待交易成功，记下 Lasna 合约地址及部署交易。
5. 点击“部署测试金库”。按提示切回 Sepolia 后再次点击；在钱包核对 0.01 Sepolia ETH 和 Gas，确认后记下金库地址及部署交易。
6. 点击“连接监听与金库”，切换 Lasna 并确认绑定交易。注意：绑定前的达标事件不会补发。
7. 可先向金库存入低于阈值的 RCAMP。存入是转账，如果转出账户匹配且达到阈值，会触发规则。
8. 点击“测试触发”，切回 Sepolia，用规则指定的账户向自己转出阈值数量的 RCAMP，核对 Gas 后确认。自转不会把代币转给别人，但需要足够 RCAMP 和测试网 Gas。
9. 等待并点击“刷新链上状态”。先看到源交易，再看到 Lasna 监听和回调请求，最后金库记录相同源交易且暂停提款，才证明实际执行。打开 Sepolia、Lasna 浏览器核对各交易和事件；网络延迟、查询范围限制或欠费都可能使证据暂不可见。
10. 可由金库 owner 自行确认“恢复提款”交易。规则已经退订，不会重新监听；如需再次演示，需部署新规则和金库。

## 遇到等待或失败

- 确认两条 RPC 可访问、网络正确、事件的 token、转出账户和单笔金额匹配、绑定发生在转账之前。
- 刷新页面读取监听合约余额/系统欠费、金库余额/代理欠费与代理储备。读取失败显示无法确认；欠费可能阻止回调。
- 不要把“没有记录”解释为失败或成功。到浏览器查 Lasna 请求与 Sepolia 代理、金库事件。页面无法可靠地自动判定所有回调失败原因。
- 不要反复发送测试转账期待这条已触发的规则自动重试：成功请求回调后它已退订。直接向金库转账不自动清除已有代理欠费；参照 [官方费用文档](https://dev.reactive.network/economy) 处理，并由用户亲自决定和确认任何充值交易。
